关于这个网站

2026-05-10 · 技术

2026年5月10日  ·  技术  ·  前端, GitHub

这个网站使用纯静态 HTML/CSS/JS 构建，部署在 GitHub Pages 上，复刻自 Butterfly 主题风格。这篇文章记录它的技术细节。

技术栈

  • 结构 — 纯手写 HTML，无框架、无构建工具
  • 样式 — CSS 变量驱动的主题系统，玻璃拟态（Glassmorphism）风格
  • 交互 — 原生 JavaScript：文章数据驱动渲染、筛选、季节粒子特效
  • 托管 — GitHub Pages，免费静态托管

特色功能

  • 四季主题 — 根据月份自动切换春夏秋冬的主题色与背景，也可以手动切换
  • 季节粒子 — 春天的蝴蝶、夏天的流萤、秋天的落叶、冬天的雪花
  • 深色 / 浅色模式 — 一键切换，跟随系统偏好
  • 数据驱动 — 文章列表存放在 data/posts.json，首页动态渲染
  • 分类 / 标签筛选 — 点击侧边栏或文章卡片上的分类标签即可过滤
  • 响应式 — 完整适配桌面端与移动端

设计灵感

整体视觉风格参考了 Hexo 的 Butterfly 主题：毛玻璃卡片、圆角布局、柔和配色、首屏全屏横幅。我用纯 CSS 变量实现了它的核心观感，同时加入了季节变化的动态元素。
